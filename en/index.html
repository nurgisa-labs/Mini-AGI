02 /The first pilot

Start with one workflow.
Then build a system.

We do not start with “AI for everything”. We start with one process where decisions get lost: incoming messages, meetings, documents or tasks.

Day1

Gather the inputs

Messages, meetings, documents and links. We identify where context breaks down.

Day3

Add memory

We connect the project, people, earlier decisions, constraints and sources to the new draft.

Day7

Demonstrate the workflow

Replies, tasks and meeting notes remain drafts. External actions require approval.

First, we test one real workflow. We do not hand every process over to AI at once.

03 /Limits on autonomy

AI prepares.
People decide.

Autonomy comes only after review. A draft has sources; an external action needs your approval.

  1. 01

    Facts can be checked

    A link, a file or a clear “unverified” label — not a claim without a source.

  2. 02

    External actions are not automatic

    Money, clients, publications and legal matters require review. A person approves the action and the final wording.

  3. 03

    Memory holds confirmed decisions

    The decision returns to project context so the next meeting does not start from scratch.
