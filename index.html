Проектная компания · отчёты для руководства

Отчёт для генерального и исполнительного директора: совпадают ли часы, записанные в системе управления проектами, с работой за компьютерами сотрудников. Отдельно — письмо о рисках по проектам: претензии и замечания без ответа, приостановка работ. Программа только читает данные и ничего не меняет в системах компании. Каждая версия проходит автоматические проверки до установки.

Чем занимаемся

ИИ для руководителей и команд

Отчёты для руководства по данным компании, контроль рисков по проектам, подбор государственных закупок, разбор больших пакетов документов. ИИ готовит, человек проверяет и решает.

Умные устройства · в разработке

Устройство под задачу: электроника, прошивка, корпус для 3D-печати. Сейчас делаем датчик присутствия без камеры.

Кибербезопасность · новое направление

Безопасно подключаем ИИ к данным компании: отдельная учётная запись, доступ только на чтение, проверка прав до запуска.
